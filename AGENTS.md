# Agent Guidelines

This repository currently relies on clear documentation rather than extensive automation. When editing files in this repo:

- Keep README and other docs tightly aligned with the implemented TypeScript CLI. Avoid promising features that are not present in `src/`.
- Prefer concise, scannable Markdown: short paragraphs, bullet lists, and fenced code blocks for commands.
- When you update usage instructions, double-check environment variable names against `src/config.ts`.

These instructions apply to the entire repository.
